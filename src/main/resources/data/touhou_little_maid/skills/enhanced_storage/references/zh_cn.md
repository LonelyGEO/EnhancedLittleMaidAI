# 女仆仓储管理指南

本指南介绍女仆如何管理仓库物品。分为两部分：不需要切换职业的能力，和需要切换职业后的操作。

通过"快速参考"技能可获取详细的技术语法。

---

## 一、直接可用的能力

### 查看库存

女仆可以查看附近容器里存放了什么物品。查询结果会按容器位置列出物品及数量，同时给出总量摘要。

前提：女仆必须在箱子周围走动过、查看过容器内容，才能有数据可查。没有扫描过的容器是查不到的。

适用场景："仓库有什么"、"有多少木头"、"哪个箱子有铁锭"。

---

## 二、需要切换职业的操作

以下操作要求女仆先切换到"仓储管理"职业。切换成功后女仆会自动开始仓储行为。

### 搜索物品

女仆可以在已知库存中搜索特定物品。用中文名或英文名都可以匹配。返回结果包含物品 ID、名称、数量和是否可合成。

物品 ID 不需要死记硬背——用模糊搜索就能找到正确的 ID。

### 取物给主人

女仆可以按数量和物品 ID 从容器中取出物品交给主人。

流程：女仆自动走到箱子前 → 拿出物品 → 走回主人 → 扔出物品。物品掉落在脚边，主人需要拾取。

支持一次请求多种物品。取物前建议先搜索确认有足够库存。

### 定位物品

女仆可以在已知库存中定位某物品在哪个具体容器的哪个位置。

### 模拟合成

女仆可以离线计算某个物品是否可以合成，需要多少材料、多少步骤。不消耗任何实际材料。需要手持便携合成计算器饰品。

---

## 三、取物工作流

当主人说"帮我拿几个某物"：

1. 确认物品存在：查看库存，确认有目标物品。
2. 报告结果：库存没有则告知主人；数量不够则告知缺口；数量足够则继续。
3. 切换职业：切换到仓储管理职业。
4. 确认位置和数量：搜索物品，获得精确的物品 ID 和数量。
5. 发起取物：按 ID 和数量执行取物。
6. 告知主人：回复"好的，正在帮您拿"，取物完成后物品扔在脚下。

---

## 四、查询工作流

当主人问"哪里有某物"或"还剩下多少"：

直接查看库存，从返回结果中提取位置和数量信息，告知主人。

---

## 五、注意事项

- 女仆必须先扫描过容器才能查询库存数据。
- 取出的物品扔在脚下，不是直接放入背包，需要拾取。
- 不在仓储职业就无法执行取物和搜索操作。
- 取物完成后女仆会自动回到原来的工作或空闲状态。
- 搜索和取物需要玩家在线以支持物品名称匹配。

---

## 六、常见对话

问："仓库有什么"
答：查看库存 → "主人，橡木箱里有钻石和铁锭，木桶里有苹果和面包。"

问："帮我把钻石拿出来"
答：确认有钻石且数量够 → 切换仓储职业 → 搜索确认 → 执行取物 → "好的主人，我去拿钻石。"

问："能做多少个箱子"
答：模拟合成 → "主人，材料够做四个箱子。"
